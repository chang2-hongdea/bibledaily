GitHub 연결

읽기는 토큰 없이도 되지만, 저장과 발행 버튼은 토큰이 필요합니다. 토큰은 이 브라우저에만 저장되고 어디로도 전송되지 않습니다.

토큰 만드는 법
  1. github.com/settings/personal-access-tokens/new 열기
  2. Token name: bibledaily-admin, Expiration: 1년
  3. Repository access → Only select repositories → bibledaily 선택
  4. Permissions → Repository permissions에서
    Actions: Read and write  /  Contents: Read and write
  5. Generate token → 나온 값을 위 칸에 붙여넣기
